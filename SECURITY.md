# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it by emailing **m.e.ondras@proton.me**.

Please include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact

## Scope

This policy applies to the CFUK Token smart contract deployed on Solana.

## Response

I will acknowledge receipt within 48 hours and provide updates on the resolution.
